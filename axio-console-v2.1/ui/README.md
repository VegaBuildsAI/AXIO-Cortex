# AXIO Console frontend

Local React interface for the AXIO Chat, Cowork, and Code modes.

```powershell
npm install
npm run dev
```

The frontend connects to the local AXIO API at `http://127.0.0.1:8765`.
Use the parent `run_ui.cmd` launcher to start the complete application.

The local launcher uses the native Next.js development server. The vinext
configuration remains available only for a future explicit Sites build.
